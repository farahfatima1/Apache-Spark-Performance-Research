# Apache Spark Performance Research

## Research Title
Evaluating the Impact of CPU Core Allocation, Dataset Size, and Data Format on Apache Spark Processing Performance.

## Overview
This research evaluates Apache Spark performance under different CPU core allocations, dataset sizes, and data formats.

## Research Objectives
- Evaluate the impact of CPU core allocation.
- Analyze performance across different dataset sizes.
- Compare CSV and Parquet formats.
- Measure execution time and memory usage.
- Analyze processing performance using statistical methods.

## Technologies Used
- Python 3.10
- Apache Spark 3.5.6
- PySpark
- Java 17
- Pandas
- Windows 11

Performance evaluation of Apache Spark using controlled experiments involving CPU allocation, dataset size, data formats, execution time, and memory consumption.
